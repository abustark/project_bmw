# Awesome DESIGN.md

74 DESIGN.md files from real websites. Each DESIGN.md is a plain-text design system (tokens, typography, color, spacing, components) for high-quality UI generation.

**Usage:**
1. Pick a brand: `design-md/linear.app/DESIGN.md`, `design-md/apple/DESIGN.md`, `design-md/stripe/DESIGN.md`, etc.
2. Copy its DESIGN.md content into your project's `DESIGN.md` or reference it in prompts.
3. Tell agent: "build me a page that looks like DESIGN.md" — agent generates UI matching that brand's design language.

**Files:** `design-md/<brand>/DESIGN.md` — 74 brands available. See `design-md/README.md`.

**Install source:** https://github.com/VoltAgent/awesome-design-md
